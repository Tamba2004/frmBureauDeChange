# Bureau de Change International 🌍

## Présentation

Bureau de Change International est une application de bureau développée en C# avec Windows Forms dans le cadre d'un projet de programmation.

L'application simule le fonctionnement d'un bureau de change permettant de consulter les taux de change et de convertir différentes devises en dollar canadien (CAD), et inversement.

## Fonctionnalités

- Consultation des différents pays et de leurs devises.
- Affichage des valeurs actuelles des monnaies.
- Conversion de CAD vers une monnaie étrangère.
- Conversion d'une monnaie étrangère vers CAD.
- Gestion des opérations de change.
- Gestion des pays et des devises.
- Interface graphique interactive.
- Module de bonus.

## Technologies utilisées

- C#
- .NET
- Windows Forms
- Visual Studio
